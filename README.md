Personal portfolio website: about, skills, education, experience, projects and contact.

## Sections

`Hero` · `About` · `Skills` · `Education` · `Experience` · `Projects` · `Contact` · `Footer`, each a React component in `src/components`.

## Run locally

```bash
npm install
npm run dev      # development server
npm run build    # production build in dist/
```
